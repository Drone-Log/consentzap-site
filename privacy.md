# ConsentZap privacy policy

Last updated: 21 November 2026 · HTML version: https://consentzap.app/privacy.html

**Short version: ConsentZap collects no personal data.** It has no accounts, no analytics and no telemetry, and it makes no network requests of its own.

## What the extension does on your device

- On the pages you visit, it detects consent banners and answers them with the most restrictive choice offered.
- It reads the site’s own consent record (for example a consent cookie or the IAB TCF data a site exposes) to check that the refusal was saved.
- It blocks requests to known tracking domains using a list that ships inside the extension.
- It keeps, only for the open tab and only on your device, the names of the consent tools it handled, their status, and the host names of blocked trackers, so the popup can show them. This is cleared when the tab closes or the browser quits.
- Your settings (protection on/off, debug logs) are stored in the browser’s extension storage on your device.

## What leaves your device

Nothing, from the extension itself. The answers ConsentZap gives to consent banners are sent to the website by the site’s own consent tool, exactly as if you had clicked the buttons yourself.

## “Copy report”

The popup can copy a status report to your clipboard. It contains the site name, the page address without query parameters, consent tool names, statuses and blocked tracker host names — no cookie values. It is only shared if you paste it somewhere.

## This website

consentzap.app is a static site. It sets no cookies, runs no analytics and loads no external fonts or scripts. The hosting provider (GitHub Pages) may keep standard server logs, such as IP addresses, for security and operations.

## Changes

If this policy changes, the new version will be published on this page with a new date.
